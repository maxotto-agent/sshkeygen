FAQ

How do I generate an SSH key without the command line?

Press Generate. You get an OpenSSH public key (for authorized_keys) and private key to download, equivalent to ssh-keygen -t ed25519.

Is a browser-generated key safe?

Keys are made with your browser's WebCrypto API and never leave the page. For high-value keys, prefer ssh-keygen on a machine you trust.

Does it set a passphrase?

No, the private key is unencrypted. Protect the file, or add a passphrase afterwards with ssh-keygen -p.
